Skill Gap to Job Matching Agent is an AI based career assistant that helps students and job seekers find suitable job opportunities based on their skills. It analyzes a resume, extracts education, skills, projects, certifications, and experience, and compares them with job requirements. The system identifies matched and missing skills for each job and provides a clear skill gap analysis. It recommends suitable training resources for missing skills and estimates the time and cost required to become job ready. The Opportunity Unlock feature identifies skills that can open more job opportunities. The system uses AI agents, LangChain, LangGraph, Groq, Python, Streamlit, PyPDF, and Pandas. The project provides a personalized learning path that connects a candidates current skills with future career opportunities.
